# Project Brain

## Overview
An e-learning platform focusing on medical and skincare courses (e.g., "دبلومة العناية بالبشرة الشاملة"). Designed primarily for Arabic-speaking users with RTL layout.

## Tech Stack
- Frontend: React 19, TypeScript, Vite
- Styling: Tailwind CSS, Lucide React icons
- Routing: react-router-dom (HashRouter)
- Backend/Auth/DB: Supabase (@supabase/supabase-js)

## Architecture Paradigm
Single Page Application (SPA) driven by React Router. Uses Supabase for Backend-as-a-Service, handling Authentication and Database queries directly from the client.
